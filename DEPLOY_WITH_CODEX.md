# Развернуть Notes ZHKVSKY Portable на другом ПК

Репозиторий: https://github.com/duxonr/notes-zhkvsky-portable
Зафиксированный релиз: https://github.com/duxonr/notes-zhkvsky-portable/releases/tag/v0.2.0

Скопируйте следующий текст в Codex на целевом Windows-ПК:

```text
Разверни готовую Notes ZHKVSKY Portable v0.2.0 на этом Windows-ПК.

Репозиторий: https://github.com/duxonr/notes-zhkvsky-portable
Релиз: https://github.com/duxonr/notes-zhkvsky-portable/releases/tag/v0.2.0
Основная папка: C:\RELEASE\Notes_ZHKVSKY_Portable
Запуск: C:\RELEASE\Notes_ZHKVSKY_Portable\Notes.exe

1. Прочитай README.md и docs/releases/v0.2.0.md из репозитория.
2. Проверь, что это Windows x64. Скачай из релиза архив
   Notes_ZHKVSKY_Portable_v0.2.0_Windows_x64.zip и SHA256SUMS-v0.2.0.txt.
   Проверь SHA256 архива. Не устанавливай Qt, MSVC, CMake или Ninja:
   все библиотеки готовой Portable-сборки уже находятся внутри архива.
3. До обновления выясни, существует ли целевая папка и запущен ли её Notes.exe.
   Не затрагивай другую установленную программу Notes и её AppData.
4. Если есть прежняя Portable-версия, полностью закрой её с сохранением
   и создай отдельную резервную копию всей папки, включая Data и Settings.
   Не удаляй и не перезаписывай существующие Data и Settings.
5. Сначала распакуй архив в отдельную тестовую папку с собственной пустой базой.
   Проверь фактические пути командой Notes.exe --verify-portable-isolation:
   отчёт Settings/isolation-report.txt должен указывать только на эту папку.
   После этого проверь запуск, создание и сохранение тестовой заметки,
   повторное открытие и доступность Pro/Kanban.
6. После успешной проверки разверни файлы программы в основную папку.
   При обновлении копируй только файлы программы и библиотеки;
   исключи из замены корневые папки Data и Settings.
   Для новой установки оставь эти папки пустыми — программа создаст данные сама.
7. Notes.exe должен запускаться непосредственно из основной папки без установки.
   Не меняй исходный код, функции, интерфейс, зависимости и настройки пользователя.
8. В отчёте дай путь к Notes.exe, путь резервной копии, результат проверки запуска
   и сохранения. Если GUI недоступен, честно укажи, что запуск не проверен.

Функциональный коммит: e599750cf23d6172bce9d9d0b16260e675fe2826.
SHA256 Notes.exe:
b81faa07f45eedc5202c82002185c5fc3d0dc00047d5febe0a868321b4be0725

Сохраняем поведение v0.2.0:
- Pro/Kanban включены, автоматические обновления выключены.
- Data/notes.db и изображения Data/Attachments рядом с программой.
- Настройки Settings/Settings.ini рядом с программой.
- Enter выходит из callout с отступом; Ctrl+Enter продолжает его.
- Рамка callout левее текста — это согласованное расположение.
```

## Перенос существующих заметок

Релиз не содержит ваших заметок. Для переноса закройте Notes на исходном ПК,
скопируйте всю рабочую папку либо обе папки `Data` и `Settings` вместе.
Одного `notes.db` недостаточно, если есть фотокарточки: нужны `Data/Attachments`.
Не заменяйте данные на другом ПК автоматически, если там уже есть свои заметки.
