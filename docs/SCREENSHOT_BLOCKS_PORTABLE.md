# Notes ZHKVSKY — Screenshot Blocks MVP

## Использование

Запускайте `Notes.exe` непосредственно из папки программы. Установка Qt не требуется.

- Установите курсор в заметке и нажмите **Ctrl+V**, если в буфере скриншот. Изображение из Проводника тоже можно скопировать и вставить.
- Через контекстное меню редактора доступна команда **Добавить изображение…** (PNG/JPEG/WebP при наличии соответствующего плагина Qt).
- Обычный текст вставляется как текст. Если одновременно представлены текст и изображение, приоритет у текста; локальный файл изображения из Проводника имеет приоритет перед его текстовым URL. HTTP-изображения автоматически не загружаются.
- Щёлкните заголовок карточки, измените его и нажмите Enter либо перейдите к другому элементу. Пустой заголовок допустим; подсказка не сохраняется.
- Щёлкните описание для редактирования. Длинное описание открывается в компактном окне с переносами и прокруткой. Стрелка появляется при фактическом переполнении двух строк. Esc или щелчок снаружи закрывает окно. Карточка остаётся высотой 96 px.
- Щёлкните миниатюру, чтобы открыть оригинал в стандартной программе Windows.
- Корзина появляется при наведении. Удаление карточки отменяется Ctrl+Z; повторяется Ctrl+Y. Оригинал немедленно не удаляется.

Карточки размещаются между абзацами; текст до и после них остаётся обычным Markdown. Kanban работает с текстовыми задачами, а карточка изображения служит границей описания задачи. Карточки не отображаются как задачи на Kanban-доске. Заголовок изображения не меняет заголовок заметки.

## Данные и перенос

```
Notes.exe
Data/
  notes.db
  Attachments/<uuid>.png|jpg|jpeg|webp
  Thumbnails/<asset-uuid>.png
  Recovery/                  # только при ошибке записи SQLite
Settings/
  Settings.ini
```

Метаданные карточек и их положение хранятся в `notes.db` вместе с содержимым заметки. В базе нет больших бинарных изображений и абсолютных путей к ним. Копии карточек имеют разные UUID, но могут ссылаться на один оригинал.

Для переноса полностью выйдите из программы через **Quit/Выход**, включая системный трей. Скопируйте всю Portable-папку на другой ПК или диск; затем запустите находящийся в ней `Notes.exe`. Папка должна быть доступна для записи. Пробелы и кириллица в пути поддерживаются.

Для резервного копирования сохраняйте **всю папку Data** и **Settings**. Только `notes.db` недостаточно: без `Attachments` оригиналы восстановить нельзя. `Thumbnails` — восстанавливаемый кэш: отсутствующая миниатюра создаётся в фоне из оригинала, когда карточка попадает в видимую область. При отсутствии оригинала карточка остаётся в заметке; нажмите на область миниатюры и укажите файл для восстановления.

Экспорт `.nbk` сопровождается соседней папкой `<имя-файла>.nbk.assets` с оригиналами и миниатюрами. Храните и переносите их **вместе**. Импорт/восстановление подхватывает этот каталог, не перезаписывая конфликтующий оригинал. При экспорте заметок в `.md`/`.txt` карточки превращаются в Markdown-ссылки с описанием, а изображения копируются в `Attachments` рядом с экспортированными заметками. Для точного восстановления интерактивных карточек используйте полную Portable-копию или `.nbk` с `.assets`; обычный импорт Markdown не превращает стандартные ссылки обратно в карточки.

## Обновление

1. Полностью закройте Notes.
2. Скопируйте рабочую Portable-папку целиком в резервный каталог.
3. Из новой сборки скопируйте `Notes.exe`, DLL, плагины, QML и остальные файлы программы.
4. **Не заменяйте и не удаляйте Data и Settings.** Не копируйте тестовую базу поверх рабочей.
5. Запустите программу и проверьте свои заметки.

Обновление не создаёт новую базу поверх существующей. Эта функция не требует миграции схемы SQLite. Старые версии Notes не понимают служебные маркеры карточек: для отката используйте полную резервную копию, сохраняя новую Data отдельно.

## Ошибки и ограничения MVP

- Оригиналы удалённых карточек, включая отменённые вставки, остаются на диске. Автоматической очистки нет: это защищает Undo, общие ссылки и резервные копии. Не очищайте Attachments вручную, если не уверены в отсутствии ссылок.
- При ошибке SQLite приложение сообщает об этом и пытается сохранить полный текст с метаданными в `Data/Recovery`. Эти JSON-файлы — аварийные копии, они не импортируются автоматически.
- Если запись оригинала не удалась, изображение удерживается в памяти до повторной попытки. Освободите место и нажмите на миниатюру. Закрытие/экспорт при несохранённом оригинале отменяются с сообщением. Принудительное завершение процесса может потерять ещё не записанное изображение.
- Декодирование миниатюр ограничено оригиналами до 160 мегапикселей. 4K входит в этот предел. Исходный файл не уменьшается и не перекодируется при просмотре; импорт из файла сохраняет исходные байты.
- Нет OCR, облака, синхронизации, встроенного просмотрщика и очистки неиспользуемых файлов.
- Для работы требуется Windows x64, совместимая с упакованным Qt 6.8.3/MSVC 2022. Проверка на отдельной чистой Windows не проводилась.

Рабочая папка `C:\RELEASE\Notes_ZHKVSKY_Portable` этой поставкой автоматически не обновляется. Новая сборка подготовлена отдельно.

## Кнопки копирования

При наведении справа доступны копирование оригинального изображения, копирование полного описания и удаление. Копирование изображения сохраняет разрешение и пиксели, использует стандартные форматы изображения QClipboard и PNG; заголовок и служебные данные не копируются. Копирование описания сохраняет весь текст и абзацы. Уведомление об успехе появляется после проверки буфера; при занятости выполняются короткие повторные попытки. Пустое описание оставляет буфер без изменений.

В текущем комплекте Qt доступны PNG и JPEG; WebP требует совместимого плагина Qt Image Formats и сейчас не включён.
